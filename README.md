# Satyam Yadav — Video Editor Portfolio

A premium, responsive portfolio website for Satyam Yadav, a video editor with 3 years of experience serving YouTubers, influencers and business owners.

## Included
- Hero + showreel
- Right-to-left category scroller on desktop
- Advertising, Product Reviews, Reels & Shorts, Explainers
- Video cards with project descriptions
- Direct WhatsApp CTA for each project
- About + Services sections
- Contact form with a simple Node backend; enquiries are saved to `data/leads.jsonl`
- Fully responsive mobile layout

## Run
Requires Node.js 18+.

```bash
npm start
```
Open: http://localhost:3000

## Add your videos
Put your files in `public/media/` using the filenames below, or change the paths in `public/app.js`:

- showreel.mp4
- ad-1.mp4
- ad-2.mp4
- product-1.mp4
- reel-1.mp4
- reel-2.mp4
- explainer-1.mp4

Optional poster images can use the same basename with `.jpg` (e.g. `ad-1.jpg`).
